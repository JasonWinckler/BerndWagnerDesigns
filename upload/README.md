# Bannerbilder der Startseite

In diesen Ordner können die beiden austauschbaren Bannerbilder der Startseite hochgeladen werden:

| Datei | Zuordnung |
| --- | --- |
| `BannerLinks.png` | Linkes, oberes Dreieck – **Luxurious Collection** |
| `BannerRechts.png` | Rechtes, unteres Dreieck – **Streetwear Collection** |

Im Repository werden bewusst **keine Platzhalter- oder Binärdateien** mitgeliefert. Bitte beide Bilder unter den oben genannten Dateinamen als PNG hochladen. Empfohlen sind Bilder im Querformat mit mindestens 2000 × 1400 Pixeln. Der wichtige Bildinhalt sollte nicht unmittelbar am diagonalen Rand liegen, da die Motive dort zugeschnitten werden. Die Startseite bindet beide Dateien automatisch ein; eine Änderung am HTML ist nicht nötig.
