# Bannerbilder der Startseite

Neben den Startseitenbildern enthält dieses zentrale Upload-Verzeichnis die
Kollektion-Ordner `luxury/` und `streetwear/`. Sämtliche Geräteversionen greifen
auf diese gemeinsamen Ordner zu, sodass jedes Produktbild nur einmal hochgeladen
werden muss.

In diesen Ordner können die beiden austauschbaren Bannerbilder der Startseite hochgeladen werden:

| Datei | Zuordnung |
| --- | --- |
| `BannerLinks.png` | Linke Bildhälfte – **Luxurious Collection** |
| `BannerRechts.png` | Rechte Bildhälfte – **Streetwear Collection** |

Beide transparenten PNGs müssen dieselben Abmessungen und denselben Bildausschnitt besitzen. Sie werden auf der Startseite pixelgenau übereinandergelegt, damit ihre diagonalen Kanten ohne Versatz das vollständige Banner ergeben. Die aktuellen Master-Hälften sind 1672 × 941 Pixel groß.
