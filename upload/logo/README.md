# Logo-Upload

Das Logo des Willkommen-Popups liegt als `bernd-wagner-designs.svg` in diesem Ordner.

Zum Austauschen die Datei unter demselben Namen ersetzen. Empfohlen wird ein transparentes SVG oder PNG mit großzügigem Freiraum, hohem Kontrast auf dunklem Hintergrund und einer Mindestbreite von 640 px. Bei einem anderen Dateinamen muss der `src`-Pfad in der Landingpage und allen vier Auflösungsvarianten angepasst werden.
